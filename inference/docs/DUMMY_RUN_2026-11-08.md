# First inference run on the GPU machine (2026-11-08): wrap-up

Goal: run the already fine-tuned NER model (`models/HeMed_Anonimizer_Model`) on the fake samples on the hospital GPU box
(A40, conda env `pii`) before training the baseline, without git conflicts between the dev and remote machines.
Result: it runs (CUDA, 30/30 rows per file, about 2 s per file). Output quality has defects, listed below.

## How to run (nobody needs PowerShell or git)
| Task | Command (activated env, repo root) |
|---|---|
| De-identify a file | `deidentify.bat file.csv [label\|mask\|x] [model]` or `python inference/de_identify.py --input file.csv` |
| Results somewhere else | `--output-dir <folder>` (default: next to the input) |
| Run the fake samples | `inference\run_dummy.bat [model]` -> `inference/dummy_results/` (no git) |
| Share the fake results (maintainers only) | `inference\push_dummy_results.bat` (commits and pushes `inference/dummy_results/` only) |

Python: `.venv` is used only if complete (`.venv\pyvenv.cfg` exists); otherwise the active environment's `python`.
Folders: `inference/dummy_data/` (fake inputs, tracked), `inference/dummy_results/` (fake outputs, tracked),
`input/`, `output/`, `models/` (git-ignored; real data and models only).
Guard: `inference/check_dummy_results.py` aborts the push unless every file in `dummy_results/` is an output of a
`dummy_data` file with identical ids and texts, and nothing outside that folder is staged. It prints no text.

## Setup/workflow issues met and fixed
1. Wrong model assumed: `D:\HeMed All\HeMed Final Model\{model_non_anon,model_anon}` are base models with no NER head.
   The trained one is `models\HeMed_Anonimizer_Model` (copy it by hand; `models/` is git-ignored).
2. `ModuleNotFoundError: toolz` in env `pii`: `pip install toolz` (already in `requirements.txt`).
3. Tracked dummy outputs sat next to the inputs, so each run dirtied the tree and would conflict on pull.
   Fix: `--output-dir`, the separate `dummy_results/` folder, `*_deid_*` ignored inside `dummy_data/`, old tracked outputs removed.
4. A PowerShell smoke script was added, then removed: users ran inference without PowerShell before.
   `deidentify.bat/.sh` fall back to the active python.
5. `No pyvenv.cfg file`: a broken leftover `.venv` on the remote beat the active env. Fix: use `.venv` only if complete.
6. `run_dummy.bat` pushed to git automatically, wrong for real data and for other users. Fix: split into a run script
   (no git) and a maintainer-only push script with the guard above.
7. Harmless messages: `TRANSFORMERS_CACHE` deprecation warning; "use a dataset" warning (sequential GPU pipeline).
   Rows are processed one by one: fine at this size, a speed issue for large data (see to-do).

## Output defects found (60 rows read in `dummy_results/`; none fixed yet)
Pipeline bugs (fixable in code):
- **P1, privacy leak: email prefix.** `genetics.clinic@ichilov.org.il` -> `genetics.[CONTACT]`; the span starts at `clinic@`.
- **P2, dates split.** `15.03.2024` -> `[DATE].[DATE].[DATE]` (19 of 30 in `test.csv`). Written dates break worse:
  `2 במרץ 2024` -> `[DATE]-[CONTACT]02`, `15 בספטמבר 2023` -> `[DATE]-[DATE][CONTACT][DATE]`, `3 בינואר 1940` -> `[DATE]-[DATE]-[DATE]`.
  Suspect: the date-normalisation stage rewrites dates before the NER sees them. Not confirmed.
- **P3, Hebrew prefix removed.** `בחיפה` -> `[LOC]`, `ברמב"ם` -> `[MED_ORG]` (the `ב` goes with the entity).
- **P4, hyphenated surname split.** `אלמוג-כץ` -> `[LAST_NAME][LAST_NAME]` (hyphen lost).
Model errors (address with training/baseline):
- **M1, leak:** `פנינה אוחנה` -> `פנינה [LAST_NAME]`; `ח'אלד עבד אל-רחמן` -> `[LAST_NAME] [LAST_NAME]`.
- **M2, wrong labels:** `אליהו משה` FIRST+FIRST; `קיבוץ יגור` MED_ORG (should be LOC); `סוראסקי` `[ORG][MED_ORG]`;
  `987654` and `H-456789` CONTACT (should be INNER_ID).
Good: names, IDs, phones, most addresses and hospitals; age masked only above 89; repeated names in long notes masked consistently (0 leaks of `repeated_name`).
